# Together Tuesdays — The Order of the Fin

Live site: https://vlad-klymenko.github.io/together-tuesdays/

A dark fantasy and shark themed absence bureau for a board game group.

All submission fields are required: name, meetup date, explanation, supporting documents, a fresh device location, and confirmation that the documents and coordinates may be shared with the group. Device location is read only after a click and browser permission, then shown for review. Coordinates, accuracy, and capture time accompany new guild announcements. Existing privately recorded locations remain private on retries.

GitHub Pages serves this static frontend. Submissions, encrypted configuration and storage use the managed backend at https://together-tuesdays-excuses.fondanvil.chatgpt.site. The Guildmaster link opens its protected organiser controls. No access code is required. Direct private record details and original document downloads remain restricted to their originating browser session and organiser, while shared group copies may be retained by members.

The repository contains no credentials or user submissions. Publishing source: main branch, repository root. No build dependencies are required.
