# Together Tuesdays — The Order of the Fin

A dark fantasy and shark themed absence bureau for a board game group.

Live site: https://vlad-klymenko.github.io/together-tuesdays/

GitHub Pages serves the static frontend. The existing managed backend handles submissions, encrypted configuration and private evidence at https://together-tuesdays-excuses.fondanvil.chatgpt.site. The Guildmaster link opens the protected organiser controls on that backend.

Visitors need no access code. Location capture is optional and requires device permission and a separate attachment choice. Supporting documents are mandatory. Private documents and locations remain restricted to their originating browser session and the organiser. The static repository contains no credentials or submission data.

Publishing source: default branch, repository root. No build dependencies are required.
